# AGENTS.md — Proxmox HA Kubernetes

## Entrypoint

- All operations go through `make`. Run `make` (no args) for full target list.

## Command order

- **Full deploy**: `make all` (runs `make nodes` → sleep 120s → `make cluster`).
- **Step by step**: `make nodes` → wait for VMs to boot → `make cluster`.
- **Teardown**: `make cluster-reset` first, then `make destroy`.

## Make targets

| Target | What it does |
|---|---|
| `nodes` | Terraform init/apply — provisions VMs, generates `ansible/hosts` |
| `destroy` | Terraform destroy (targets VMs only) |
| `cluster` | Full cluster setup via Ansible |
| `cluster-upgrade` | Rolling upgrade (serial=1 on control planes) |
| `cluster-reset` | Tear down cluster config (run before `destroy`) |
| `apps` | Ansible — core apps (ingress-nginx, cert-manager, metrics-server) |
| `apps-extras` | Ansible — extra apps (portainer) |
| `apps-reset` | Ansible — uninstall apps |
| `cluster-kubeconfig` | Generate kubeconfig via Ansible |
| `rocky` / `ubuntu` | Build VM templates with Packer (optional; Terraform downloads cloud images directly) |
| `ANSIBLE_ARGS=` | `make cluster ANSIBLE_ARGS="--tags cni --check"` |

## Config locations

- `.env` — API tokens, loaded by Makefile + Terraform + Packer. **Do not commit** (in `.gitignore`).
- `terraform/variables.tf` — VM specs, IPs, SSH keys (`id_ed25519` by default).
- `ansible/group_vars/all.yml` — k8s version (currently `1.36.1`), CNI (`cilium`), runtime (`containerd`).
- `ansible/group_vars/control_planes.yml` — kube-vip VIP + LB range.
- `ansible/group_vars/workers.yml` — CSI plugin (`longhorn`).

## Architecture

- **3 control planes** (Rocky Linux, 2C/2GB/20GB) with kube-vip HA (VIP: `192.168.30.100`).
- **3 workers** (Ubuntu 24.04, 4C/6GB/80GB) with Longhorn CSI.
- **Network**: VLAN 30 (`192.168.30.0/24`), bridge `vmbr1`.
- **CNI**: Cilium (configurable to Calico/Flannel in `all.yml`).
- **Terraform provider**: `bpg/proxmox` ~> 0.106.0, reads `.env` directly.

## Quirks

- Ansible inventory (`ansible/hosts`) is auto-generated by Terraform — **do not edit manually**.
- Ansible `host_key_checking=false`, uses `~/.ssh/id_ed25519`, `serial: 1` on control planes.
- Packer VM templates are optional. Terraform pulls cloud images from upstream URLs at apply time.
- `.env` must exist with `PROXMOX_API_URL`, `PROXMOX_API_TOKEN_ID`, `PROXMOX_API_TOKEN_SECRET`.
- No CI, no tests, no pre-commit hooks, no linters — pure IaC.
